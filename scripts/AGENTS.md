# scripts/AGENTS.md

各ステージは前段の JSON 配列を読み、自分の JSON 配列を書く独立プロセス。
ここには「読む・ドメイン関数を呼ぶ・書く」以外を置かない。**テストしたくなったら太った合図。**

ステージ境界は論文が報告するファネルの段に一致させてある (`README.md`)。

- **件数不変**: 入力件数 = 出力件数。落ちたケースも `status` 付きで 1 件残す。
  フィルタで消すと分母が消え、ファネルが作れなくなる
- **例外を投げない**: ケース単位の失敗は結果に記録して次へ。プロセスを落とすのは I/O 失敗のみ
- 上 2 つは `src/io.ts` の `runStage` が強制する。**各ステージで自前の try/catch を書かない**
- **全再実行が原則。** 増分キャッシュを作らない。`id` が全ステージ共通の主キー
- 出力は 2 層。`NN-stage.summary.json` は目視レビューの対象、`NN-stage.detail/<id>.json` は ID で引く。
  **サマリが目視で読めるサイズに収まらないなら、記録している中身が多すぎる**
- 引数を取らない。入出力パスは各ファイルに固定で書く
- 4 ファイル固定。使い捨てスクリプトは `experiments/<日付>-<名前>/` へ
